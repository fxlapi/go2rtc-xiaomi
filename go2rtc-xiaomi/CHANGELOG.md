# 更新日志

## 1.9.15-p8（2026-11-19）

- 一键添加摄像头改为行内输入英文流名称：点「添加」后出现输入框（回车或点「确定」提交，Esc/「取消」还原），
  流名称只允许英文字母开头（可含数字、下划线、短横线），不再把云端中文名写进配置；
  重名会提示换名，不再自动加后缀。
- 云端中文名仅作播放页/流管理页显示：添加成功后保存在浏览器本地（localStorage），
  显示时优先取本地映射，其次内置对照表，最后回退原名；配置文件保持纯英文。

## 1.9.15-p7（2026-11-19）

- 流管理新增「小米账号登录」：输入小米账号（手机号/邮箱）+ 密码登录，需要时输入短信/邮箱验证码或图形验证码；
  登录后自动列出账号下的摄像头，点「添加」即完成接入，无需再手填 xiaomi:// 地址；
  已登录账号的凭证保存在本机配置中，之后打开自动列出设备；已添加的摄像头会标记「已添加」。

## 1.9.15-p6（2026-11-19）

- 兼容 HA ingress 访问：界面所有接口请求改为相对路径（按当前页面路径自动推导 API 前缀），
  修复经「打开网页界面」（ingress 子路径）访问时接口全部 404 的问题；直连 1984 端口不受影响。

## 1.9.15-p5（2026-11-19）

- 整站替换：原版 go2rtc 全部网页（首页/流列表/添加/配置/日志/网络/单流播放页等）全部移除，
  打开 `http://<主机>:1984/` 即为整合界面（深色）：画面（打开即播）/ 流管理 / 日志 / 配置；
- 移除 `/panel/` 独立面板与 `panel/` 目录，界面全部内置于二进制；
- 勾选记忆沿用原监控台记录，之前在 `/panel/` 勾选的摄像头会自动带过来。

## 1.9.15-p3（2026-11-19）

- 首页改版：打开 `http://<主机>:1984/` 即自动播放所有摄像头画面（MSE 直播），
  首次打开默认全选，勾选记忆、拖动排序、双击全屏、静音、断流自动重连；
- 顶部新增按钮切换原版功能页：流列表（原首页移至 streams.html）/ 添加 / 配置 / 日志 / 网络；
- 原 `/panel/` 监控台保持不变。

## 1.9.15-p2（2026-11-18）

- 新增内置「监控台」面板：插件启动后自动在 `/panel/` 提供整合页面，无需任何配置。
  - 画面：多摄像头 MSE 直播（直连 go2rtc WebSocket），勾选记忆、拖动排序、双击全屏、断流自动重连；
  - 流管理：列表 / 添加 / 编辑 / 删除（写入 go2rtc 配置文件），内置小米摄像头来源模板；
  - 日志：实时查看，支持只看警告错误、清空；
  - 配置：在线编辑 go2rtc.yaml，保存或保存并重启。
- go2rtc 源码补丁：api 模块新增 `panel_dir` 配置（默认探测 `/app/panel` 与 `./panel`），
  在 `/panel/` 路径提供静态文件服务，不影响原版 Web UI 与其他接口。

## 1.9.15-p1（2026-11-18）

基于 go2rtc v1.9.15：

- PR #2575：登录后持续排空 CS2 命令队列，修复「pop buffer is full」卡顿（原版备份 go2rtc.orig-1.9.15）。
- CW501D 双镜头单连接合并：
  - session pool 单连接复用 + StartMediaDual 双画质命令（社区 commit b713d79）；
  - 修复副镜头 channel=2 映射（producer.go：channel 1/2 均映射到内部通道 1）；
  - CW501D 通道解析改按包头 flags 位 0x01400000 判断（client.go），hdr[28] 对该机型无效；
  - HDRDBG 诊断日志默认关闭，设环境变量 GO2RTC_DEBUG_HDR=1 开启。
- 实测：双流同拉仅 1 条 TCP 连接，两路画面独立（抓帧对比确认）。
