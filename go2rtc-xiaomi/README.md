# go2rtc (xiaomi)

基于 [go2rtc](https://github.com/AlexxIT/go2rtc) v1.9.15 深度定制的 Home Assistant 插件，专为小米摄像头优化。在原版强大的流媒体能力之上，修复了小米摄像头的播放卡顿问题，并内置了一套开箱即用的中文管理界面。

## 本仓库特点

- **修复播放卡顿**：解决小米摄像头长时间播放中出现的「pop buffer is full」卡顿（登录后持续排空命令队列）。
- **双镜头单连接**：双摄摄像头（如 CW501D）两个镜头合并到同一条连接，只占用 1 个摄像头连接位；先开哪个镜头都能正常出双画面。
- **内置中文界面**：打开网页即是监控台——画面（打开即播、勾选记忆、拖动排序、双击全屏、断流自动重连）、设备、日志、配置四个页面，无需任何配置。
- **米家账号直连**：支持扫码登录（米家 App 扫二维码）或密码登录，登录后自动列出账号下的摄像头，点「添加」即完成接入，无需手填地址。
- **一键添加默认最高清**：新添加的摄像头自动选择最高清晰度。
- **名称自动同步**：摄像头显示名自动同步为米家 App 里的实际名称。
- **兼容 ingress**：经 Home Assistant「打开网页界面」子路径访问同样正常。

## 安装方法

1. 在 Home Assistant 中进入 **设置 → 附加功能**；
2. 点击右下角 **「添加功能」**，首次使用先在右上角菜单选择 **「仓库管理」**（或直接在添加页面填入仓库地址）；
3. 填入本仓库地址：

   ```
   https://github.com/fxlapi/go2rtc-xiaomi
   ```

4. 刷新后即可看到 **go2rtc (xiaomi)** 插件，点击安装并启动；
5. 打开插件页面的 **「打开网页界面」**，或直接访问 `http://<主机IP>:1984/` 进入管理界面。

## 快速上手

1. 打开管理界面，进入 **设备** 页，用米家 App 扫码登录（或输入账号密码）；
2. 在设备列表中点击 **「添加」**（双摄摄像头可分别添加镜头1 / 镜头2）；
3. 回到 **画面** 页勾选摄像头，即可观看；配置与日志均在对应页面在线管理。
